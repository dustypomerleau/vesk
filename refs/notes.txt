troubleshooting post loading:

steps:
1. routes/+page.ts calls load()
1. the load function calls fetch and hits the api defined in routes/api/info/+server.ts
1. the handler in that file calls utils.getPosts()
1. that function calls vite's import.meta.glob, and then maps over the returned files and returns an array of objects with metadata and a path for each post
1. those objects are returned via the api as JSON, and then deserialized into PostPath in the load() function of +page.ts
1. routes/+page.ts passes those PostPath to the Info component
1. Info component passes each post to a Listing
1. Listing destructures and uses some of the metadata for the home page listing of articles
1. Listing also wraps itself in an anchor tag that links to the path of the article, using the path on PostPath
1. that link fails - props meta is undefined, and the failrue is probably in the load function at routes/info/[slug]/+page.ts
